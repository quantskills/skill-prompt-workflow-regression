# 可选评估与正式确认

本页仅用于活动申报、证据整理、模型审查或负责人验收，不是安装、离线示例或用户数据分析的前置条件。未做这些评估也可运行工具，但不能声称已经正式验收。

如需模型辅助审查，可在明确授权的环境中使用 DeepSeek Flash 整理证据，或使用其他已授权模型审查代码。模型意见不是独立实验、数据真实性认证或成交证明；不要上传凭据、未授权行情或私人会话。

历史活动建议质量分口径为完成 30、方法 35、平台 25、文档 10；这是活动评估口径，不是工具自动计算的结果。价值系数和最终得分由负责人确认，程序或同一审查模型不能自行盖章。

提示词题历史难度系数为 0.85，不得沿用到另两题。跨市场日频范围的难度仍需另行确认；CTA 未知系数保持未知。模型审查通过、测试数量增加或运行成功不构成提高研究效果评分的理由。

历史平台复验、负结论、时间证据缺口和成交限制仍以 README 与各自验证记录为准。正式确认前按原始输入、冻结配置、运行环境与原始输出逐项核验，区分本地测试、平台复算和实际成交，不能相互替代。
