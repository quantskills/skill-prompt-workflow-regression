# 中文检查与 JSON 输出

EVO 1.1.15 的一次实际测试中，纯英文键名的批量 JSON 被中文检查要求重写。模型重写后加入代码围栏或自然语言解释，导致原本数值正确的回答无法按冻结协议解析。

不要通过放宽评分、强行提取代码围栏中的片段来掩盖问题。可在 JSON 内加入中文说明值，保留约定键名和原生数值类型，并明确禁止在 JSON 外附加文字。例如：

```json
{"说明":"本次结果已按输入规则逐项校验。","responses":[{"task_id":"size-1","output":{"quantity":50}}]}
```

本轮修订版在开发集和保留集各完成三次独立调用，均返回可解析的正确结果。这只证明该版本、模型和任务集上的兼容性，不是所有 EVO 版本都必需的固定写法。遇到不同平台行为，先保存原始错误与重写记录，再在开发集验证，不能用保留集反复试提示词。
